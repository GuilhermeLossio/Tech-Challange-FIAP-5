    Security baseline

    ECloe Pay validates the simulated confirmation step, locks the session, uses idempotency, separates Pay-owned state in PostgreSQL, and never asks for real payment credentials.

    ECloe Pay demo terms

    ECloe Pay is a demonstration application. It does not create real users, process real money, move funds, authorize payments, approve credit, perform fraud checks, or provide regulated financial services.

    All balances, transactions, wallet benefits, rewards, and confirmations are synthetic and session-scoped. Do not enter real card, bank, CPF, password, or account information.
